# Map marker glyphs

Category glyphs rasterized into the MapLibre world map (`src/styles/map.css` accent, dark basemap).
Contract: `viewBox="0 0 24 24"`, 24x24, artwork inside a 20x20 safe area, single-color via `currentColor`, no prolog/style/filter/gradient/external refs.
MVP placeholders drawn by an engineer — a UX designer replaces them; keep the filenames and the contract when swapping.
Exception: `seal.svg` (CLAIMED badge) is two-tone and hardcodes white `#ffffff` body + `#ed6b00` check; it is not recolorable.
